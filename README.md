## 📂 Contenido del Repositorio

A continuación se detallan los principales scripts y proyectos incluidos:

### 🎮 Proyectos Destacados
* **[`viborita.py`](viborita.py)**: Clásico juego de la serpiente (*Snake Game*) desarrollado con interfaz gráfica usando la librería `tkinter`. Incluye puntuación, colisiones y controles fluidos.
* **[`padeltorneo.py`](padeltorneo.py)**: Sistema de gestión y organización para torneos de pádel. Permite registrar jugadores por categoría y persistir los datos en un archivo de texto (`jugadores.txt`).
* **[`cajeAuto.py`](cajeAuto.py)**: Simulación interactiva de un cajero automático por consola con operaciones de consulta de saldo, depósitos, extracciones y validación de fondos.

### 📝 Actividades y Prácticas de Clase
* **[`holaMundo.py`](holaMundo.py)**: El primer paso en todo lenguaje, probando la salida por consola.
* **[`act1.py`](act1.py) a [`act4.py`](act4.py)**: Ejercicios de clase enfocados en:
  * Entrada y salida de datos (`input` / `print`).
  * Manipulación y concatenación de cadenas de texto (*strings*).
  * Estructuras de control condicionales (`if`, `elif`, `else`).
  * Estructuras de repetición (`while`, `for`).

## 🛠️ Tecnologías y Conceptos Aplicados

- **Lenguaje:** [Python 3](https://www.python.org/)
- **Librerías GUI:** `tkinter` (interfaz de usuario para juegos)
- **Conceptos de Programación:**
  - Tipos de datos primitivos (enteros, flotantes, cadenas, booleanos).
  - Manejo de flujo y condicionales.
  - Bucles y lógica interactiva.
  - Estructuras de datos (listas y tuplas).
  - Lectura y escritura de archivos de texto (`I/O`).
  - Funciones modulares y funciones de retorno.

## 🚀 Cómo Ejecutar los Proyectos

1. **Clonar este repositorio:**
   ```bash
   git clone https://github.com/fabriciosabugo/Programacion-I.git
   ```

2. **Acceder a la carpeta del proyecto:**
   ```bash
   cd Programacion-I
   ```

3. **Ejecutar cualquier script:**
   * Para jugar a la viborita:
     ```bash
     python viborita.py
     ```
   * Para probar el cajero automático:
     ```bash
     python cajeAuto.py
     ```
   * Para el gestor de torneo de pádel:
     ```bash
     python padeltorneo.py
     ```
